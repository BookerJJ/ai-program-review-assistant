# Reproducing Saved Results

This guide reproduces the **objective evaluation** of the published, synthetic outputs. It does not rerun the models, re-score semantic judgment, or modify any frozen prompt or golden expectation.

## Environment

From the repository root (Python 3.12):

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

No `GEMINI_API_KEY` or Ollama server is required for the offline evaluation below.

Scenario inputs and frozen goldens are in `src/benchmark_cases_v1.py`, `src/benchmark_golden_v1.py`, `src/holdout_cases_v1.py`, and `src/holdout_golden_v1.py`.

## Offline commands

```bash
python -m src.evaluate_smoke
python -m src.benchmark_evaluator_v1
python -m src.benchmark_compare
python -m src.holdout_evaluator_v1
python -m src.model_comparison_evaluator_v1
```

These read the stored results and write derived CSV/JSON reports. They do **not** call model APIs. They may rewrite generated evaluation reports; perform this in a clean checkout if you want to inspect file diffs.

The expected headline **objective** values are:

| Dataset/model | Structural | Strict Evidence |
|---|---:|---:|
| 30-case v0.5 dev | 82.2 | 88.6% |
| 30-case v0.6 dev | 85.2 | 96.7% |
| 20-case qwen final | 86.0 | 97.5% |
| 20-case Gemini comparison | 93.6 | 100.0% |

Structural and Strict Evidence are deliberately separate. **20/20 completed inference cases is a reliability count, not an accuracy score.**

## Semantic-review artifacts

- qwen v0.5: `results/benchmark_v1/human_review/benchmark_human_evaluation_completed.csv`
- qwen v0.6: `results/benchmark_v1/human_review_v06/benchmark_human_evaluation_v06_completed.csv`
- qwen final: `results/holdout_v1/human_review/holdout_human_evaluation_completed.csv`
- Gemini final: `results/model_comparison_v1/gemini_3_8_flash/human_review/gemini_human_review_scored.csv`

The human-named semantic score is the mean of five reviewer-assigned 0–2 dimensions divided by 10 and converted to 0–100. The Gemini ratings were **generated by an AI assistant applying this rubric**; they have not been independently reviewed by a second human judge. Reproducing these aggregate numbers from CSV is not equivalent to independently validating the case ratings.

## Live inference: separate activity

New inference requires Ollama or the hosted API and can produce different results. Keep the published canonical outputs immutable. Do not rerun the frozen holdout or Gemini comparison runners into these result paths; use a separate experiment directory and version if you want a new evaluation. Hosted API quotas and terms may differ from those observed during the original experiment.
